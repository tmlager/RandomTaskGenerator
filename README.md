Автор: Денис Калинкин 
Курс: Итоговая аттестация (GUI-разработка)  

## Описание проекта:

«Random Task Generator» — это графическое приложение на Python с интерфейсом Tkinter, которое помогает случайным образом выбирать задачу из списка.  
Вы можете:

- Генерировать случайную задачу
- Добавлять свои задачи с категорией (учёба / спорт / работа)
- Фильтровать задачи по категории
- Просматривать историю всех сгенерированных задач
- Сохранять историю в JSON-файл (автозагрузка при запуске)

Приложение полезно для планирования дня, борьбы с прокрастинацией или просто для рандомных активностей.
